# Viamind

Open-source PCB design suite in Rust. Clean-room — see [CLEAN_ROOM.md](CLEAN_ROOM.md).

| Crate | Purpose |
| --- | --- |
| `viamind-core` | Shared data model (units, geometry, nets) |
| `viamind-schematic` | Schematic capture |
| `viamind-pcb` | PCB layout |
| `viamind` | Application binary |
