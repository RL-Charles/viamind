# Clean-room policy

Viamind is an independent implementation. It contains no code, assets, or
data derived from proprietary EDA software.

## Allowed sources
- Observed behaviour of software you are licensed to use
- Publicly published documentation, tutorials, and videos
- Open standards (IPC-2581, ODB++ public spec, Gerber X3, IPC-7351, STEP)
- Open-source projects under compatible licences (with attribution)

## Forbidden
- Decompiling, disassembling, or debugging proprietary binaries
- Copying proprietary code, libraries, icons, or UI assets
- Using proprietary trademarks in product, crate, or feature names

## Process
1. Write a behavioural spec in `docs/specs/` citing public sources only.
2. Implement from the spec alone.
