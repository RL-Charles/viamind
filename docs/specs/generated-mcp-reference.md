# Generated agent tool reference and reproducible workflows

Ticket T-0096, parent S-033. Independent implementation from public protocol
documentation and this repository's existing application contracts.

## Public sources

- [MCP tools, 2025-03-26](https://modelcontextprotocol.io/specification/2025-03-26/server/tools):
  discovery includes tool definitions and optional continuation cursors.
- [MCP transports, 2025-03-26](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports):
  stdio uses UTF-8 JSON-RPC records separated by newlines; diagnostic stderr is separate.
- [Claude Code MCP configuration](https://code.claude.com/docs/en/mcp), consulted
  2026-10-11: stdio launch commands follow `--`; HTTP accepts an endpoint URL.

These sources define interoperability only. Tool descriptions and schemas come
from the actual Viamind registry, and examples are original.

## Discovery and deterministic reference

Add a Python standard-library generator accepting an explicit executable path.
Launch the full `viamind --headless` in a fresh, owned process and temporary working
directory. Perform initialize, initialized notification, then tools/list until no
nextCursor. Do not call editing tools during catalog generation. Require engine
tools so the identification-only skeleton cannot accidentally generate the docs.
Validate unique nonempty bounded names, object input schemas, response identities,
protocol errors, pagination and declared tools capability. Preserve the complete
tool objects, including schemas, definitions, annotations and optional metadata.

Use a 60-second whole-session deadline, 15 seconds per response, a 4 MiB record
limit, 32 MiB total stdout, 1 MiB stderr, 128 notifications, 64 pages, 512 tools,
4096-byte cursors and 128-character names. Refuse repeated cursors, duplicate
names, invalid UTF-8/JSON, unexpected replies or requests, and bounded-depth or
non-finite JSON. Drain stderr alongside stdout to prevent pipe deadlock; reject
oversized unterminated records promptly. Wait for each reply before closing stdin,
and terminate only the owned child on errors. Clean exit is required.

Sort tools by name and recursively sort object keys. Produce stable UTF-8 JSON
and Markdown with every complete tool object in a fenced JSON block, escaped
index labels and deterministic anchors. Select fences longer than any backtick
run in a tool definition. The stable catalog records only format/protocol and
tool definitions, with no timestamps, process paths, source hashes or host names.
An optional separate verification report records executable SHA-256, negotiated
protocol, counts and catalog hashes. Hash the executable before and after use.

The default publication creates a NEW directory containing both reference files,
staged beside the destination and published atomically without replacement.
Reject existing destinations including symlinks. A separate `--check` compares
both generated byte strings with regular bounded committed files without writes.
Repository updates use a fresh output directory then explicitly copy the two
reviewed files. Errors leave existing output untouched.
